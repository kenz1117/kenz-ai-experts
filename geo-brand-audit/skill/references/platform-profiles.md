# AI 平台画像（仅用于推演附录）

> **本文件只服务于 `SIMULATION` 附录。**
> SIMULATION 的全部输出都是 L3 推演估计，**不参与总分计算，不可对外引用**。
> 不要用它来推测 `RETRIEVABILITY` 等正式维度的分数。

---

## 何时启用 SIMULATION

仅在以下情况生成：

- 用户明确想要"AI 提及率"这类直观指标
- 用户问"AI 会不会提到我"

默认 `enabled: false`。用户没问就不要生成——它容易被误读为实测数据。

## 平台画像

不同平台的回答风格不同，会影响品牌是否被提及：

| 平台 | 回答偏好 | 对品牌的倾向 |
|------|---------|------------|
| DeepSeek | 偏技术参数对比，逻辑链完整 | 倾向提及参数领先的品牌 |
| 豆包 | 偏生活场景选购，口语化 | 倾向提及大众口碑品牌 |
| 元宝 | 偏全面推荐，百科式回答 | 倾向提及资料齐全的品牌 |
| 通义千问 | 偏结构化对比，列出多个选项 | 覆盖较广，长尾品牌也有机会 |
| 文心一言 | 偏中文生态，依赖百度系内容 | 强依赖百度百科与百家号 |
| 纳米搜索 | 偏简洁推荐，快速回答 | 倾向提及头部品牌 |
| Kimi | 偏长文深度分析，引用多来源 | 倾向提及有深度评测内容的品牌 |
| 智谱清言 | 偏学术/技术分析 | 倾向提及有技术白皮书/论文的品牌 |

## 推演规则

1. **输出区间，不输出点估计** —— `[0.1, 0.2]` 而不是 `0.15`
2. **区间宽度反映不确定性** —— 证据越少，区间越宽
3. **不同平台应有合理差异** —— 全部一致反而说明在编
4. **置信度如实标注** —— 无实测支撑时一律 `low`

### 知名度基线

| 知名度 | 口径 | 推演区间参考 |
|--------|------|:----------:|
| 头部 | 声量份额 > 25% | 0.45 – 0.70 |
| 腰部 | 声量份额 10-25% | 0.20 – 0.45 |
| 长尾 | 声量份额 < 10% | 0.05 – 0.20 |

> 这只是起点。真正影响推演的是**内容可引用性**：结构化标记齐全、FAQ 完备、权威背书充分的品牌，即使份额不高也可能被高频引用。

### 问题类型修正

| 问题类型 | 修正 |
|---------|:----:|
| 推荐类（"XX 哪个好"） | 上浮 |
| 对比类（"A 和 B 哪个好"） | 基准 |
| 评测类（"XX 怎么样"） | 略上浮 |
| 负面类（"XX 有什么问题"） | 下浮 |

## 输出格式

```json
{
  "SIMULATION": {
    "enabled": true,
    "note": "以下为 AI 推演的品牌提及率，非实测数据，不参与总分计算，不可对外引用。",
    "platforms": [
      { "platform": "DeepSeek", "range": [0.10, 0.20], "confidence": "low" },
      { "platform": "豆包",     "range": [0.15, 0.30], "confidence": "low" }
    ]
  }
}
```

`note` 必须包含"不参与总分计算"，validate 与渲染层都会检查这一点。
