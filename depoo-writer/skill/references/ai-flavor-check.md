# 去 AI 味终检（L5）

> 基于 humanizer-zh 的 24 种 AI 写作模式（源自 Wikipedia: Signs of AI writing），按迪谱学长文风做了适配。
> **⚠️ 有 5 条规则与本号文风直接冲突，已标注豁免——冲突时以本号文风为准。**

---

## 零、冲突豁免（先读这个，别机械执行）

humanizer 是**通用**去痕工具，它不知道迪谱学长要什么，有几条规则会误伤本号的核心笔法。

| humanizer 原规则 | 迪谱学长的处理 | 为什么 |
|---|---|---|
| **删除金句**<br>（听起来像可引用的就删） | **豁免 —— 本号必须有金句，每篇 3-5 处** | 金句是本号的招牌笔法，不能删。真正要禁的是**万能金句**（见下方判定法）。 |
| **粗体过度使用** | **调整**：加粗只给金句，全文 ≤5 处 | 不给术语加粗，不给强调加粗 |
| **破折号过度使用** | **调整**：允许用，全文 ≤3 处 | 本号允许破折号，但禁止「揭示前必加破折号」的滥用 |
| **三段式法则** | **调整**：排比递进是本号招牌，全文 ≤2 处 | 禁止每段都搞三项列举 |
| **否定式排比** | **部分适用**：「不仅…而且…」禁用；「不是 A，是 B」是本号金句公式，保留 | |

### 金句判定法：删「万能金句」，留「专属金句」

humanizer 要删的金句，指的是**放之四海皆准的漂亮话**——AI 最爱堆这种。本号要留的，是**只对这篇文章成立的具体判断**。

| ❌ 万能金句（删） | ✅ 专属金句（留） |
|---|---|
| AI 时代，唯一不变的就是变化 | 工具人人都能下载，但知道往哪儿用的人还是少数 |
| 拥抱变化，才能赢得未来 | 先想清楚要解决什么问题，再挑工具。顺序反了，怎么选都是错的 |
| 技术终将普惠每一个人 | 以前这活得排期等技术资源，现在运营自己就能配出来 |

**判定方法**：把金句单独抽出来，问一句「这句话能原封不动套到任何一篇 AI 文章上吗？」——能，就删；只有这篇成立，就留。

## 一、24 种模式扫描

### A. 内容模式（最致命，命中即改）

**A1. 过度强调意义与遗产**
警惕词：标志着、见证了、是……的体现/证明/提醒、至关重要、凸显/强调/彰显、象征着、奠定基础、关键转折点、不可磨灭的印记、深深植根于、不断演变的格局
→ 删掉这些词，直接说事实。

**A2. 过度强调知名度**
警惕词：据报道、知名专家指出、拥有活跃的社交媒体账号
→ 要么给具体出处，要么删。

**A3. -ing 结尾的肤浅分析**
「……，确保了……」「……，反映了……」「……，为……做出贡献」
→ 拆成两句，或直接删掉后半截。

**A4. 宣传广告式语言**
警惕词：拥有（夸张）、充满活力的、丰富的（比喻）、深刻的、令人叹为观止的、开创性的（比喻）、必游之地、迷人的
→ 换成具体事实。

**A5. 模糊归因**
警惕词：行业报告显示、专家认为、有观点指出、多个来源表明
→ **本号硬要求**：硬数字必须有可核验来源，否则删。与 L1 事实核验联动。

**A6.「挑战与未来展望」八股**
警惕词：尽管……面临若干挑战、尽管存在这些挑战、未来展望
→ 本号用「反鸡汤降温」替代，不写这种套路段落。

### B. 语言与语法

**B7. AI 高频词**
此外、至关重要、深入探讨、强调、持久的、培养、获得、突出（动词）、相互作用、复杂性、关键（形容词）、格局、展示、织锦、宝贵的、充满活力的
→ 逐个换掉或删掉。与 SKILL.md 文风禁区第 2 条叠加执行。

**B8. 系动词回避**
用「作为……」「代表着……」「拥有……」替代简单的「是」「有」
→ 改回「是」「有」。

**B9. 否定式排比**
「不仅是……，而且是……」→ 禁用，直接说结论
「不是 A，是 B」→ **保留**，这是本号金句公式

**B10. 三段式列举**
强行把想法分成三组 → 改两项或四项。排比递进全文 ≤2 处。

**B11. 同义词循环**
一段里换三种说法指同一个东西（「这个工具 / 该产品 / 这款应用」）
→ 统一成一个词。

**B12. 虚假范围**
「从 X 到 Y」但 X 和 Y 不在同一量级
→ 拆开直说。

### C. 风格模式

**C13. 破折号过度** — 全文 ≤3 处，禁止「揭示前必加破折号」。

**C14. 粗体过度** — 只给金句，全文 ≤5 处，禁止给术语加粗。

**C15. 内联标题垂直列表**
`- **用户体验：** 用户体验得到显著改善`
→ 改散文叙述（与 SKILL.md 文风禁区第 4 条一致）。

**C16. 标题大写** — 中文不适用，跳过。

**C17. 表情符号** — 正文禁止 emoji。**例外**：尾部三连话术里的 ⭐ 保留（固定话术）。

**C18. 弯引号混用** — 统一中文引号：金句用「」，对话用""。不混用中英文引号。

### D. 交流模式

**D19. 协作交流痕迹**
警惕词：希望这对您有帮助、当然！、您说得完全正确、这是一个……
→ 本号基本不会有，但扫一遍防止混入。

**D20. 知识截止免责**
警惕词：截至某日期、根据我的训练数据、虽然具体细节有限
→ 删。

**D21. 谄媚语气**
「好问题！您说得对，这确实是个复杂的话题」
→ 删。

**D22. 填充短语**
「为了实现这一目标」「由于……的事实」「在这个时间点」「值得注意的是」
→ 简化（与 SKILL.md 文风禁区第 1 条叠加）。

**D23. 过度限定**
「可能、也许、某种程度上、在一定意义上」叠加使用
→ 保留一层，删掉其余。

**D24. 通用积极结论**
「未来可期」「激动人心的时代即将到来」
→ **本号强要求**：用「反鸡汤降温」替代（见 L3-6）。

### E. 本号新增（第 25 条）

**E25. 泛称「用户」堆积与生硬说理腔**（2026-08-29 实战复盘新增，复发率最高）

humanizer 的 24 条是通用规则，漏了这一条——而它恰恰是读者说「不像人话」的头号原因：**真人聊天不会反复说「用户」**，更不会用统计口吻给一堆人下判断。

| ❌ 生硬 | ✅ 自然 |
|---|---|
| 用户不搜了、改问 AI 了，那就不是用户在挑你，是 AI 在替用户挑 | 人家不问搜索引擎、改问 AI 了，那替他做决定的就不是他自己，是 AI |
| 这习惯咱们改不了 | 这事儿谁也改不了 |
| 现在用 AI 的人里，我估摸着得有九成，是把豆包当百度使的 | 我自己也差不多……身边人十有八九都这样 |
| 别觉得这是小题大做 | 这不算小事 |
| 而这个位子你买不到 | 而这个位子买不到 |
| 非技术人也能跑 | 不懂代码也能跑 |
| 而且这事比"搜不到"还狠一层 | 更狠的还在后头 |

**量化红线**：全文「用户」**≤2 处**（加粗金句里的可保留）；**禁止同一句内出现 2 次**；「咱们」「别觉得」「你总得」应为 0。

## 二、灵魂检查（去完痕还要有魂）

去掉 AI 模式只是及格线。无菌、没声音的写作和机器生成一样明显。

- [ ] **有观点**：不是中立罗列，有明确的「我的判断是……」
- [ ] **承认复杂**：有「这令人印象深刻但也有点不安」式的复杂感受
- [ ] **感受具体**：不是「这令人担忧」，而是「盯着后台看了半天没敢信」
- [ ] **允许混乱**：有一处跑题或半成型的想法，完美结构反而像算法
- [ ] **节奏变化**：长短句交错，不是每句一个长度

（与 L4 角度不同：L4 看「像不像人写的」，这里看「有没有魂」。）

## 三、快速检查清单（发布前最后一扫）

- [ ] 连续三个句子长度相同？→ 打断其中一个
- [ ] 段落都以单行短句结尾？→ 变换结尾方式
- [ ] 揭示前有破折号？→ 删（全文保留 ≤3 处）
- [ ] 解释了类比或比喻？→ 相信读者，删掉解释
- [ ] 用了「此外」「然而」？→ 考虑删
- [ ] 三段式列举？→ 改两项或四项
- [ ] **金句万能测试**：抽出来能套到任何 AI 文章上？→ 重写成只对这篇成立
- [ ] **翻译宣告**：「翻译成人话」「说人话」「简单说，它就是」→ 删（见 L3-2）
- [ ] **「用户」计数**：＞2 处 → 改成「人家 / 身边人 / 他」；同一句内出现 2 次必改
- [ ] **说教腔**：出现「咱们」「你总得」「你买不到」「别觉得」→ 去掉指指点点的主语
- [ ] **硬过渡**：「而且这事比……还狠一层」「更重要的是」→ 换成「更狠的还在后头」

```bash
# 一键扫 AI 高频词（应为 0 命中）
grep -nE "此外|至关重要|深入探讨|持久的|培养|格局|织锦|宝贵的|充满活力|标志着|见证了|不可磨灭" 文章.md

# 生硬说理腔扫描（2026-08-29 新增，复发率最高）
echo "「用户」出现次数（应 ≤2）: $(grep -o '用户' 文章.md | wc -l)"
grep -nE "咱们|你总得|你买不到|别觉得|而且这事比|更重要的是" 文章.md   # 应 0 命中
```

## 四、质量评分（50 分制）

| 维度 | 评估标准 | 得分 |
|---|---|---|
| **直接性** | 直截了当 vs 绕圈宣告 | /10 |
| **节奏** | 长短交错 vs 机械重复 | /10 |
| **信任度** | 简洁明了 vs 过度解释 | /10 |
| **真实性** | 自然流畅 vs 机械生硬 | /10 |
| **精炼度** | 无冗余 vs 大量废话 | /10 |
| **总分** | | **/50** |

**迪谱学长标准**（金句和排比会略微拉低「精炼度」，标准相应下调）：
- **≥42 分** — 合格，可发布
- **35-41 分** — 有小问题，按快速清单修一遍
- **<35 分** — AI 味重，返工重写
