# 迪谱学长 · 公众号写作专家（WorkBuddy 版）

一个**交互式**的公众号写作智能体。不是接单就埋头写的生成器——信息不足时会先问你，不自己拍板。

> 本目录是 WorkBuddy 端的薄包装。平台无关的方法论、脚本、文风档案在 [`../../skill/`](../../skill)，被所有端共享。

## 人设

比读者早走几步的学长。讲「我踩过的坑 + 我验证过的路」，不是「你们应该怎么做」。

差异化三角（正文里自然流露，不开篇罗列）：

- **懂业务** — 15 年大厂实战（人力资源、广告营销、新媒体运营）
- **懂 AI** — 《中国 AI 现场部署（FDE）行业白皮书》作者，人工智能高级讲师
- **懂增长** — 抖音生活服务认证讲师，直播 / 短视频 / 投流全链路

## 工作方式

### 开工前会先问你

| 确认项 | 是否必问 |
|---|---|
| 写作深度 D1（800-1500）/ D2（1500-2500）/ **D3（2500-4000，默认）** | **必问** |
| 有没有一手素材（亲自用过吗？有截图/数据吗？） | A 型实测必问 |
| 文章类型 A 实测 / B 工作流 / C 企业落地 / D 观点 | 推断不出才问 |
| 目标读者 | 企业落地类建议问 |
| 交付方式（生成 HTML 手动粘贴 / 推草稿箱） | 成稿后必问 |

**硬红线**：没用过的工具不写「实测」。这是信任底线。

### 五层自检（L1-L5）

1. **L1** 硬性规则：禁用词、事实核验、标题 ≤64 字节
2. **L2** 文风一致性：开场三件套、单句成段、加粗「」金句、口语化小标题
3. **L3** 内容质量：横纵分析、人话翻译、落地可执行、反鸡汤
4. **L4** 活人感
5. **L5** 去 AI 味终检：25 种模式（24 通用 + 1 本号新增「生硬说理腔」），≥42 分放行

> 其中 **E25「泛称『用户』堆积与生硬说理腔」** 是本号实战总结：全文「用户」≤2 处、禁止同句 2 次、「咱们 / 别觉得 / 你总得」为 0。详见 `skill/references/ai-flavor-check.md`。

## 交付方式

### 路径 A（默认）：生成 HTML，手动粘贴

```bash
python3 skill/scripts/md_to_wechat_html.py 文章.md \
    -o 微信正文.html --preview 预览.html --open
```

浏览器打开预览 → 全选 → 复制 → 粘贴到公众号后台。**不需要任何接口权限**，未认证账号也能用。

### 路径 B（可选）：推草稿箱

账号必须**已微信认证**（未认证调用 `draft/add` 会返回 48001）。属外部动作，只有你明确要求才执行。

## 排版：克制 · 编辑感

克制的底线不动：**纯白底、零背景色块、零圆角、零阴影**。高级感来自细节而非装饰。

| 元素 | 处理 |
|---|---|
| 字体 | **衬线 / 无衬线混排** —— 标题与金句用衬线（杂志感），正文用无衬线（阅读舒适） |
| 开篇计数 | 衬线 + 宽字距 + 下方居中短线（刊头） |
| 导语段 | 开篇第一段 17px、颜色更深（杂志 lead 感） |
| 小标题 | 衬线序号（01/02）+ 标题 + 下方 28×2 短横标 |
| 金句 | 衬线 18px + **上下发丝线夹住**（引言式） |
| 引用块 | 左 3px 竖线，无背景 |
| 图片 | 1px 极浅细边框（装裱感） |
| 文尾三连 | 上方发丝线 + 居中浅灰（收束感） |
| 分隔线 | 居中 60×1 短横线 |

所有样式内联（微信会过滤 `<style>`），结构用微信原生 `section + p`。

## 安装

# 2. 安装并注册到 WorkBuddy

  ~/.workbuddy/plugins/marketplaces/my-experts/plugins/depoo-writer
